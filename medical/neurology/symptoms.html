01｜读题六格

固定拆题顺序

02｜本章知识卡

每张卡都回答“是什么、为什么、题目怎么用”。

教材印刷页
A1

先用六格拆题干

依次标出：对象与基础病、发病时间、起病状态、阳性线索、关键阴性线索、题目命令词。神经系统题最有区分力的通常是‘时间—方式—定位’。

为什么：时间判断急慢，方式区分血栓/栓塞，定位解释偏瘫、失语、吞咽或共济失调。

教材P589–611、P620–627

A2

头痛先判危险信号

突然出现的剧烈头痛，或头痛伴喷射性呕吐、意识改变、瞳孔变化和局灶性神经功能缺损，应先想到急性颅内病变或颅内压增高。

为什么：先排威胁生命的问题，再比较偏头痛、丛集性头痛、紧张型头痛等特征。

教材P589–591

A3

体位相关头痛是高价值线索

低颅压性头痛常在直立后数分钟出现或加重，卧位减轻；颅内压增高性头痛常伴呕吐、视乳头水肿或意识变化。

为什么：题干只要给‘站起更痛、躺下缓解’，体位关系往往比疼痛部位更有判别力。

教材P589–591

A4

眩晕要分周围性与中枢性线索

周围性眩晕常旋转感明显，可伴耳鸣、听力改变和明显自主神经症状；中枢性眩晕若伴复视、构音障碍、吞咽困难、共济失调等，应警惕脑干或小脑病变。

为什么：不要只看‘晕得重不重’，要看有没有听觉线索和局灶性神经体征。

教材P592–593

A5

意识评估要连续、可比较

意识状态可结合唤醒程度、言语与疼痛反应、瞳孔及脑干反射判断；GCS由睁眼、言语、运动三部分组成，总分3～15分。

为什么：连续记录比分数本身更重要；题目问恶化时，要比较前后趋势。

教材P594–596

A6

Broca与Wernicke抓一个主矛盾

Broca失语以表达困难、言语不流利为主，理解相对保留；Wernicke失语以听理解严重受损为主，口语可流利但内容错乱、答非所问。

为什么：‘说不出但听得懂’偏Broca；‘说得多但听不懂’偏Wernicke。

教材P600–602

A7

构音障碍不等于失语

构音障碍是发音相关肌肉或神经控制异常，语言理解与组词意义可保留；失语是语言中枢受损导致表达或理解障碍。

为什么：先问‘想法和语言组织是否正确’，再判断是否只是发音含糊。

教材P600–602

A8

肌力0～5级按抗阻层层递进

0级无收缩；1级有收缩无动作；2级可在床面移动但不能抗重力；3级能抗重力；4级能抗部分阻力；5级正常。

为什么：用‘有没有收缩—能不能动—能不能抬—能不能抗阻’四问定位。

教材P608–609

A9

吞咽障碍先守住气道安全

出现饮水呛咳、湿性嗓音、吞咽困难或意识下降时，进食、饮水和口服药前应先完成吞咽风险筛查，再决定进食方式。

为什么：营养重要，但气道安全优先；题目中的‘立即给水试试’常是陷阱。

教材P600–602、P624–625

A10

运动障碍的分布本身就是定位线索

偏瘫指一侧上下肢受累，截瘫多见双下肢受累，四肢瘫累及四肢，单瘫只累及一个肢体；还要结合肌张力、反射和感觉改变继续定位。

为什么：先准确描述‘哪里不能动’，再讨论病变在哪；不要把所有肢体无力都笼统写成偏瘫。

原创训练
01
症状体征失语定位

脑梗死患者能理解护士的指令，也会点头回应，但说话费力，只能说出一两个词，语言不流利。最可能的语言障碍是？

  1. A. Broca失语
  2. B. Wernicke失语
  3. C. 构音障碍
  4. D. 意识障碍

答案：A

决定性线索：决定性线索是‘理解相对保留＋表达不流利、词少’。这组表现符合Broca失语。

常见误区：构音障碍主要是发音不清，并不一定影响组词和语言表达；Wernicke失语的核心是听理解严重受损。

只改一个条件：若改成‘说话流利但内容杂乱、答非所问，并且听不懂指令’，答案改为Wernicke失语。

教材P600–602

02
症状体征肌力分级

患者右上肢肌肉可见轻微收缩，但肢体不能在床面产生位移。该侧肌力为？

  1. A. 0级
  2. B. 1级
  3. C. 2级
  4. D. 3级

答案：B

决定性线索：1级的关键词是‘有收缩、无动作’。

常见误区：2级必须已经能在床面移动，只是不能抗重力抬起。

只改一个条件：若改成‘可在床面向外移动，但不能抬离床面’，答案改为2级。

教材P608–609

03
症状体征肌力分级

患者可将小腿抬离床面并完成全范围活动，但护士轻加阻力后即不能维持。该侧肌力最可能为？

  1. A. 2级
  2. B. 3级
  3. C. 4级
  4. D. 5级

答案：B

决定性线索：能抗重力完成全范围活动，但不能抗阻力，对应3级。

常见误区：4级需要能够对抗一定阻力，5级为正常肌力。

只改一个条件：若能抗轻至中等阻力但较正常侧弱，则改判4级。

教材P608–609

04
症状体征头痛危险信号

患者头痛突然明显加重，继而喷射性呕吐、反应迟钝。护士首先应将其视为哪类信号？

  1. A. 普通紧张型头痛
  2. B. 颅内压增高或急性颅内病变警报
  3. C. 单纯睡眠不足
  4. D. 药物依赖

答案：B

决定性线索：剧烈头痛＋喷射性呕吐＋意识变化构成危险组合，应先处理潜在颅内急症。

常见误区：不能因患者既往有头痛史就把新出现的神经改变归为普通头痛。

只改一个条件：若是双侧紧箍样头痛、无呕吐和神经体征，才更接近紧张型头痛。

教材P589–591

05
症状体征体位线索

腰椎穿刺后患者坐起约10分钟出现枕部头痛，平卧后明显减轻。最有解释力的判断是？

  1. A. 高颅压性头痛
  2. B. 低颅压性头痛
  3. C. 丛集性头痛
  4. D. 脑栓塞

答案：B

决定性线索：直立诱发、卧位缓解是低颅压性头痛的典型体位线索。

常见误区：高颅压题干更常给喷射性呕吐、视乳头水肿和意识改变。

只改一个条件：若改成持续加重并伴喷射性呕吐、视物模糊，应转向颅内压增高。

教材P589–591

06
症状体征GCS计算

患者呼唤不睁眼，疼痛刺激睁眼；只能发出难以理解的声音；疼痛刺激时能回缩肢体。按GCS计算为？

  1. A. 6分
  2. B. 7分
  3. C. 8分
  4. D. 9分

答案：C

决定性线索：疼痛睁眼E2＋难以理解的声音V2＋回缩M4＝8分。

常见误区：不要把‘定位疼痛’与‘回缩’混为一谈；两者运动评分不同。

只改一个条件：若运动反应改为能定位并拨开疼痛刺激，则M5，总分改为9分。

教材P594–596

07
症状体征吞咽优先级

新发脑卒中患者清醒，但说话含糊，饮水时咳嗽。此时最优先的护理动作是？

  1. A. 鼓励多饮水练习
  2. B. 立即口服药物
  3. C. 暂停经口摄入并进行吞咽风险筛查
  4. D. 使用吸管少量饮水

答案：C

决定性线索：呛咳提示误吸风险。进食、饮水和口服药前应先完成吞咽筛查。

常见误区：吸管并不会自动降低误吸风险；在风险未明时反复试水可能增加吸入风险。

只改一个条件：若筛查通过且患者坐位稳定，才进入体位、食物性状和进食方法的选择。

教材P624–625

08
症状体征眩晕定位

患者突发眩晕，同时有复视、构音障碍、吞咽困难和走路不稳。该组线索首先提示？

  1. A. 单纯周围性眩晕
  2. B. 中枢性病变可能
  3. C. 单纯焦虑
  4. D. 体位性低血压

答案：B

决定性线索：复视、构音障碍、吞咽困难和共济失调属于局灶性神经线索，指向脑干/小脑等中枢病变。

常见误区：眩晕感强烈并不能单独证明周围性；伴随体征更有定位价值。

只改一个条件：若仅有旋转感、耳鸣和听力下降，无局灶神经体征，则更偏向周围性眩晕。

教材P592–593、P623

09
症状体征感觉障碍安全

患者左侧痛温觉减退。护士进行生活指导时最应强调？

  1. A. 用热水袋直接热敷患侧
  2. B. 洗浴前由健侧或照护者测试水温
  3. C. 增加患侧强刺激
  4. D. 忽略患侧以免受伤

答案：B

决定性线索：感觉减退会使患者不能及时察觉烫伤、压伤或外伤，需要借助健侧/照护者和环境保护。

常见误区：直接热敷和强刺激都可能在患者未察觉时造成损伤。

只改一个条件：若患者同时有患侧忽略，还要把必要物品逐步放入患侧视野并进行安全提示。

10
症状体征康复强度

偏瘫患者肌力达到3级。最符合分级训练原则的是？

  1. A. 只做完全被动活动
  2. B. 训练患肢独立完成全范围关节活动
  3. C. 立即大负荷抗阻
  4. D. 禁止主动活动

答案：B

决定性线索：教材将3级对应到能抗重力，可训练独立完成全范围关节活动。

常见误区：渐进抗阻通常在肌力达到4级后更合适；小于2级时才以助力活动为主。

只改一个条件：若肌力达到4级，可在安全范围内逐步加入渐进抗阻训练。
