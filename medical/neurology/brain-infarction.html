02｜本章知识卡

每张卡都回答“是什么、为什么、题目怎么用”。

教材印刷页
B1

脑梗死的核心因果链

供血动脉闭塞或严重狭窄 → 局部脑组织缺血缺氧 → 缺血中心不可逆损伤，周围半暗带仍可能挽救 → 出现相应部位的神经功能缺损。

为什么：治疗争分夺秒，是为了尽快恢复血流、保护仍可存活的半暗带。

教材P620

B2

脑血栓形成：静、慢、渐

常见于中老年并有动脉粥样硬化、高血压、糖尿病或高脂血症者；多在安静或睡眠中起病，可有TIA前驱，症状常在数小时至1～2天达高峰。

为什么：静息起病＋危险因素＋逐渐加重，是脑血栓形成的组合线索。

教材P620–621

B3

脑栓塞：动、急、快

脑栓塞常在活动中突然起病，数秒至数分钟达到高峰；心源性最常见，房颤是重要病因，也可见于瓣膜病、心肌梗死、感染性心内膜炎等。

为什么：活动中突发＋房颤/心脏病＋瞬间达峰，优先考虑脑栓塞。

教材P626–627

B4

早期CT正常不能排除脑梗死

头颅CT常用于尽快鉴别脑梗死与脑出血，但脑梗死发病24小时内可无明显影像改变；MRI弥散加权成像可更早显示缺血灶。

为什么：CT的第一价值常是排除出血，不是用一次阴性结果否定早期缺血。

教材P621

B5

急性期血压不宜机械追求正常

教材强调急性期血压调控应个体化、慎重、适度；应先处理疼痛、呕吐、颅内压增高和焦虑等升压因素，避免灌注骤降使缺血区扩大。

为什么：题目若只给轻中度升高、没有其他必须降压的依据，‘立即快速降至正常’通常不是最佳选择。

教材P622

B6

溶栓后恶化先警惕出血

溶栓中或溶栓后出现严重头痛、血压骤升、恶心呕吐、意识或神经功能恶化，应立即报告并准备复查CT，同时观察口鼻腔、消化道、皮肤黏膜等出血表现。

为什么：核心是识别‘治疗后新出现的出血警报’，不能把它当作原病自然波动继续观察。

教材P624

B7

脑水肿危险窗要会识别

脑水肿常在发病后3～5天达高峰，大面积梗死风险更高；剧烈头痛、喷射性呕吐、意识恶化等提示颅内压增高。

为什么：‘病情一度稳定后第3天突然意识变差’是高价值时间线。

教材P622

B8

吞咽护理：筛查—选择—防误吸

进食、饮水或口服药前先筛查；能经口者取合适体位并调整食物性状，安静进食；高误吸风险者按病情选择肠内营养途径。

为什么：先判断安全性，再谈吃什么；出现呛咳时先保护气道、清理分泌物。

教材P624–625

B9

康复不是等到完全恢复再开始

神经功能缺损不再加重、生命体征稳定后即可开展早期康复，包括良肢位、呼吸道与皮肤管理、被动或主动运动、语言和吞咽训练。

为什么：急性期也要预防压力性损伤、肺部感染、关节挛缩和肌萎缩。

教材P622–623

B10

帮助自理不等于全部代劳

按能力提供适度协助，给足时间并鼓励患者用健侧和可用功能完成进食、洗漱、穿衣、转移等活动；家属支持康复，但避免形成完全依赖。

为什么：目标是安全前提下逐步提高ADL，而不是追求护理人员做得更快。

03｜先背什么：六个维度

先把知识按用途收拢，再进入场景题。每天复习“逻辑—数字—护理”三个维度。

背诵地图
01｜机制

一条主链

血管狭窄/闭塞 → 局部缺血缺氧 → 中心区不可逆坏死、半暗带仍可挽救 → 局灶性神经功能缺损。

背诵落点：为什么抢时间？为了恢复血流、挽救半暗带。
02｜起病

两幅画像

血栓：静、慢、渐；常有动脉粥样硬化危险因素，可有TIA前驱。
栓塞：动、急、快；常有房颤等栓子来源，数秒至数分钟达峰。

背诵落点：先说起病状态和速度，再说病因。
03｜检查

三个目的

CT：先排出血，早期阴性不能排除梗死。
MRI/DWI：更早、更敏感地找缺血灶。
DSA/MRA：看血管狭窄、闭塞及其他血管病变。

背诵落点：检查名后必须跟“解决什么问题”。
04｜治疗

四个关键词

超早期、个体化、整体化；再灌注争分夺秒；血压调控慎重适度；溶栓/抗栓后重点观察出血。

背诵落点：治疗原则要和时间窗、禁忌及监测一起记。
05｜风险

三道安全门

溶栓后严重头痛/呕吐/血压骤升/神经恶化 → 警惕出血；第3～5天意识变差 → 警惕脑水肿；饮水呛咳/湿性嗓音 → 先筛查吞咽。

背诵落点：先识别危险，再写下一步动作。
06｜护理

一条答题链

评估 → 目标 → 安全与并发症预防 → 分级功能训练 → 家属参与与心理支持 → 健康教育 → 效果评价。

背诵落点：简答题不能只堆措施，要有顺序。

情境迁移
1
原创前置血栓识别

68岁患者有高血压、糖尿病和高脂血症，晨起后发现右侧肢体无力，数小时内逐渐加重，无明显剧烈头痛。更符合哪种起病模式？

  1. A. 脑血栓形成
  2. B. 脑栓塞
  3. C. 丛集性头痛
  4. D. 周围神经损伤

答案：A

决定性线索：动脉粥样硬化危险因素＋静息/睡眠中起病＋逐渐进展，是脑血栓形成的典型组合。

常见误区：不能只凭‘突然发现’就选脑栓塞，还要看发病状态和达峰速度。

只改一个条件：若改为房颤患者活动中突发偏瘫，数分钟即达高峰，则更支持脑栓塞。

思考提醒：把“睡眠或晨起发现＋渐进”稳定识别为脑血栓形成线索。

教材P620–621

2
原创前置栓塞识别

72岁房颤患者散步时突然失语、右侧肢体瘫痪，2分钟内症状达到最重。最有区分力的线索组合是？

  1. A. 年龄＋高血压
  2. B. 活动中起病＋房颤＋数分钟达峰
  3. C. 单纯右侧偏瘫
  4. D. 无发热

答案：B

决定性线索：房颤提示心源性栓子，活动中突发且数秒至数分钟达峰符合脑栓塞。

常见误区：偏瘫只说明局灶神经缺损，不能单独区分血栓形成与栓塞。

只改一个条件：若改为睡眠中起病、病前有反复TIA、症状阶梯式加重，则更偏脑血栓形成。

思考提醒：房颤先归入“心源性栓子”，再判断脑栓塞。

教材P626–627

3
原创前置影像判断

患者发病2小时，表现为突发偏瘫和失语。急诊头颅CT未见明确低密度灶。对此最合理的理解是？

  1. A. 已排除脑梗死
  2. B. 早期CT可无明显改变，仍需结合临床并进一步评估
  3. C. 一定是脑出血
  4. D. 可以直接回家观察

答案：B

决定性线索：脑梗死发病24小时内CT可无明显改变；急诊CT的重要作用之一是排除出血。

常见误区：‘CT阴性’不等于‘没有急性缺血’，时间点决定影像敏感性。

只改一个条件：若CT见脑实质高密度出血灶，则诊断路径会转向脑出血。

思考提醒：早期CT阴性不能排除脑梗死，先看它是否已排除出血。

教材P621

4
原创前置溶栓观察

患者静脉溶栓过程中突然剧烈头痛、呕吐，血压骤升，原有肢体无力明显加重。护士首要判断与行动是？

  1. A. 正常药效，继续原速观察
  2. B. 警惕出血，立即报告并准备复查CT
  3. C. 立即进食补充能量
  4. D. 鼓励下床活动

答案：B

决定性线索：溶栓后新发严重头痛、呕吐、血压骤升和神经功能恶化是出血警报。

常见误区：不要用‘原病本来会波动’解释治疗后突然出现的危险变化。

只改一个条件：若仅有穿刺点少量渗血，也要评估并报告，但危险级别低于意识和神经功能突然恶化。

思考提醒：再灌注后出现神经功能恶化，先识别出血警报。

5
原创前置血压管理

急性脑梗死患者血压较平日升高，但无其他必须紧急降压的情况。护士对医嘱理解最合理的是？

  1. A. 越快降至正常越好
  2. B. 遵循个体化、慎重、适度原则并监测灌注
  3. C. 完全不监测血压
  4. D. 自行停用所有治疗

答案：B

决定性线索：急性缺血区依赖灌注，降压过快可能使缺血扩大；教材强调个体化、慎重、适度。

常见误区：‘高血压是危险因素’不等于急性期任何升高都要立即大幅降至正常。

只改一个条件：若同时存在主动脉夹层、急性心衰等其他紧急指征，血压处理需按相应病情重新权衡。

思考提醒：急性期血压判断要同时结合灌注、诱因和题目给定阈值。

教材P622

6
原创前置脑水肿

大面积脑梗死患者发病第3天出现剧烈头痛、喷射性呕吐，意识由清醒转为嗜睡。最应优先考虑？

  1. A. 单纯疲劳
  2. B. 脑水肿与颅内压增高
  3. C. 康复过度
  4. D. 正常恢复过程

答案：B

决定性线索：大面积梗死＋第3天＋头痛、喷射性呕吐、意识恶化，与脑水肿高峰期和高颅压征象吻合。

常见误区：时间线和意识变化不能被‘住院后疲劳’解释掉。

只改一个条件：若在溶栓过程中立即出现同样变化，还要首先警惕继发出血并准备急查CT。

思考提醒：用时间线识别第3～5天脑水肿危险窗。

7
原创前置用药时序

患者刚完成静脉溶栓6小时，病情稳定。关于抗血小板治疗，最符合教材考试口径的是？

  1. A. 立即自行加用阿司匹林
  2. B. 溶栓后24小时内通常不主张应用
  3. C. 抗血小板药永远禁用
  4. D. 只要血压正常即可立刻使用

答案：B

决定性线索：教材提示不主张在溶栓后24小时内使用阿司匹林，以免增加出血风险。

常见误区：‘脑梗死需要抗血小板’必须与是否溶栓、时序和出血风险一起判断。

只改一个条件：若未行溶栓，抗血小板治疗的启动时机按教材与医嘱另行判断。

思考提醒：是否接受溶栓会改变抗血小板药物的时序判断。

8
原创前置吞咽护理

脑梗死患者清醒但吞咽困难，刚送到病房，家属准备喂水和口服药。护士最先应做什么？

  1. A. 允许少量试喝
  2. B. 先评估吞咽与误吸风险，暂缓经口摄入
  3. C. 改用吸管
  4. D. 平卧喂水

答案：B

决定性线索：脑卒中后吞咽障碍可危及气道安全，进食、饮水或口服药前需先筛查。

常见误区：平卧和吸管都可能增加风险；‘少量’不代表安全。

只改一个条件：若筛查通过，应取坐位或抬高床头并头略前屈，按能力选择适宜性状。

思考提醒：把吞咽评估、体位、食物性状和误吸处理串成顺序。

原创前置早期康复

脑梗死患者生命体征稳定，神经功能缺损不再加重，但仍卧床、右侧偏瘫。当前最合理的康复策略是？

  1. A. 完全卧床直到肌力恢复
  2. B. 在安全评估后开始良肢位和循序渐进的早期康复
  3. C. 立即高强度抗阻
  4. D. 只训练健侧

答案：B

决定性线索：病情稳定且缺损不再加重时，可开始早期康复，以减少压力性损伤、感染、挛缩和萎缩。

常见误区：长期完全卧床会增加失用和并发症；高强度训练也不符合循序渐进原则。

只改一个条件：若神经功能仍快速恶化，应先重新评估病情和急性并发症，再调整康复强度。

思考提醒：当前教材强调病情稳定条件，避免机械等待固定天数。

原创前置自理训练

偏瘫患者洗漱速度慢，家属总是代替完成。护士最恰当的指导是？

  1. A. 为节省时间全部代劳
  2. B. 在安全前提下留足时间，按能力协助患者参与完成
  3. C. 禁止家属参与
  4. D. 只在出院前一天训练

答案：B

决定性线索：自理训练的目标是逐步提高ADL。护士和家属应提供适度帮助，而非剥夺患者练习机会。

常见误区：护理做得快不等于康复效果好；全部代劳会强化依赖。

只改一个条件：若患者当日明显疲劳或病情波动，可降低任务难度，但仍尽量保留可完成的部分。

思考提醒：从“不全部代劳”扩展为完整的生活自理护理链。

真题练习最常见病因
完整卷母题·表述规范化河南科技大学2019护理综合真题（完整版）P3

脑血栓形成最常见、最基本的病因是？

  1. A. 高血压病
  2. B. 脑动脉粥样硬化
  3. C. 各种脑动脉炎
  4. D. 血压偏低

答案：B

为什么：教材把脑动脉粥样硬化列为脑血栓形成最常见和基本的病因；高血压常与之并存并相互影响，但不是本题最精准的上位答案。

迁移提醒：先用起病状态与达峰速度判断血栓性过程，再回到底层病因。

依据：教材P620

真题练习栓子来源
完整卷母题·表述规范化天津中医药大学2017护理综合真题（完整版）P8

脑栓塞最常见的栓子来源类型是？

  1. A. 气体栓子
  2. B. 心源性栓子
  3. C. 脂肪栓子
  4. D. 来源不明

答案：B

为什么：脑栓塞以心源性最常见；心源性脑栓塞中，非瓣膜性心房颤动又是最常见病因。要分清“来源类型”和“具体心脏病”两个层级。

迁移提醒：房颤、活动中突发、数分钟达峰，共同指向心源性脑栓塞。

依据：教材P626–627

13
真题练习睡眠中起病
回忆版母题·情境化改编广州中医药大学2023、中国医科大学2023、锦州医科大学2021回忆题

患者夜间入睡前无明显异常，清晨醒来发现口角歪斜、右侧肢体无力，症状随后逐渐加重。最符合哪类起病模式？

  1. A. 脑血栓形成
  2. B. 脑栓塞
  3. C. 蛛网膜下腔出血
  4. D. 癫痫全面性发作

答案：A

为什么：睡眠或安静状态起病、晨起发现、随后渐进，构成脑血栓形成的高价值组合。不能只抓“发现时突然”，要判断真正的起病状态和达峰速度。

迁移提醒：更换危险因素后，判断仍要落到起病状态和进展速度。

依据：教材P620–621

真题练习定位＋起病
完整卷母题·表述规范化杭州师范大学2011护理综合真题（完整版）P11；四川大学2011亦见同型题

45岁患者晨起发现左侧肢体瘫痪，同时有眼球震颤、共济失调和吞咽困难。题目给出的最佳诊断是？

  1. A. 脑血栓形成
  2. B. 小脑出血
  3. C. 蛛网膜下腔出血
  4. D. 脑桥出血

答案：A

为什么：“晨起发现”支持静息状态下发生的脑血栓形成；眼球震颤、共济失调、吞咽困难提示后循环受累。先用起病方式定疾病性质，再用体征判断受累系统。

迁移提醒：症状变多时，先定起病性质，再按神经定位整合体征。

依据：教材P620–621、P623

真题练习治疗时间窗
完整卷母题·教材口径河南科技大学2019护理综合真题（完整版）P3；吉林大学2018见同考点

按本教材考试口径，急性缺血性脑卒中一般治疗时间窗不超过多久？

  1. A. 6小时
  2. B. 8小时
  3. C. 12小时
  4. D. 24小时

答案：A

为什么：第7版教材总述为溶栓治疗时间窗一般不超过6小时，并在治疗要点中强调发病后3～4.5小时内早期溶栓。做题时先看题目问的是“教材一般时间窗”还是“具体静脉溶栓方案”。

迁移提醒：时间窗决定再灌注机会；治疗后的出血观察和抗血小板时序决定护理安全。

依据：教材P620、P622

真题练习CT鉴别
回忆版母题·情境化改编苏州大学2021、天津中医药大学2022回忆题

患者突发偏瘫2小时，急诊CT未见明显低密度灶。下列解释最合理的是？

  1. A. 可完全排除脑梗死
  2. B. 早期脑梗死CT可无明显改变，仍需结合临床并排除出血
  3. C. 一定是脑栓塞
  4. D. 应等待24小时后再做任何评估

答案：B

为什么：脑梗死发病24小时内CT可无明显改变；急诊CT的重要作用是尽快排除脑出血。MRI弥散加权成像可在更早阶段显示缺血灶。

迁移提醒：早期CT阴性只说明暂未见明确梗死征象，不能脱离发病时间与临床表现下结论。

依据：教材P621

真题练习版本校准题
历史完整卷·按现行教材校准中南大学2013护理综合真题（完整版）P6

旧题曾问：脑血栓形成患者病情稳定后，患侧肢体功能锻炼一般何时开始。复习现行第7版教材时，最应掌握的判断标准是？

  1. A. 必须固定等待1周
  2. B. 神经功能缺损不再加重且生命体征稳定，即可进行早期康复
  3. C. 肌力恢复至5级后
  4. D. 出院后再开始

答案：B

为什么：旧题的固定时间答案反映旧版口径；第7版教材改为以病情稳定性作为启动条件。考研复习应以目标院校指定教材版本为准，并理解“早期康复是为了减少并发症和失用”。

迁移提醒：康复启动要看病情是否稳定，避免机械套用固定天数。

依据：教材P622–623

真题练习自理缺陷简答
完整卷母题·答案结构化延安大学2019护理综合真题（完整版）P9

简述缺血性脑卒中患者生活自理能力缺陷的护理措施。

答案：答题骨架：评估能力 → 保证安全 → 分级训练 → 适度协助 → 家属参与 → 评价效果

为什么：①评估意识、肌力、平衡、认知及ADL；②保持良肢位，防跌倒、压力性损伤和误吸；③把进食、洗漱、穿衣、转移拆成小步骤，鼓励健侧带动患侧；④给足时间，只在需要处协助，避免全部代劳；⑤提供心理支持并教会家属正确协助；⑥以参与度、ADL提高和并发症是否发生评价效果。

迁移提醒：作答时先排除“全部代劳”，再按评估、安全、训练、协助、评价展开。

真题练习诊断＋进食护理
回忆版母题·病例重建南方医科大学2023护理综合真题回忆版

患者晨起出现偏瘫、失语，头颅CT早期未见出血；入院后饮水呛咳。请写出医疗诊断、3个优先护理问题，并说明经口进食前后的护理要点。

答案：医疗诊断：脑血栓形成（需结合后续影像确认）。护理问题可写：躯体移动障碍、言语沟通障碍、吞咽障碍/误吸风险。

为什么：进食链应写全：进食/饮水/口服药前筛查吞咽 → 选择坐位或床头抬高并头前屈 → 调整食物性状、少量慢食、安静进餐 → 不用吸管盲目试水 → 呛咳时头偏向一侧并清理分泌物、保持气道通畅 → 记录摄入及有无误吸。

迁移提醒：把早期影像判断与吞咽护理顺序分别写清，再按优先级整合。

真题练习综合病例
回忆版母题·病例重建中南大学2023护理综合真题回忆版P2

患者有高血压、高脂血症和反复TIA史，夜间服药休息后，次日晨起晕倒并出现右侧偏瘫、口角歪斜。请完成：诊断、诊断依据、主要护理问题和护理措施。

迁移提醒：综合题要把疾病识别、急性风险和恢复期护理串成一条线。
