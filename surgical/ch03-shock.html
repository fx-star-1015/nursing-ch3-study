03｜核心知识卡

一张卡只保留一个可命题的结论；背会后直接打勾。

结论＋常见考法
01｜本质

组织灌注不足

有效循环血量锐减导致微循环障碍、细胞缺氧和代谢紊乱。

考点怎么出：定义题要落在“有效循环血量”和“组织灌注”，不能只写低血压。

教材P30

02｜分型

按病因识别

低血容量、感染、心源性、神经源性和过敏性休克处理重点不同。

考点怎么出：血压正常不排除早期休克，脉率与脉压差往往更早变化。

教材P30—32

03｜分期

代偿到失代偿

早期脉快、脉压差小、皮肤凉；进展后血压下降、少尿与意识障碍加重。

考点怎么出：多器官低灌注证据越多，严重程度越高。

教材P32—34

04｜观察

趋势胜过单点

意识、皮温色泽、脉搏、血压、脉压、尿量需连续观察。

考点怎么出：心率110、收缩压90，指数约1.22，不可被“还有血压”误导。

教材P33—36

05｜指数

休克指数

心率/收缩压；≥1提示休克，>2提示严重。

考点怎么出：复苏后血压回升但尿量仍低，不能轻率判断纠正。

教材P36

06｜尿量

肾灌注窗口

<25 ml/h提示灌注不足，>30 ml/h常提示复苏改善。

考点怎么出：必须把CVP与血压、临床反应联读。

教材P36

07｜CVP

容量与心功能线索

正常5—12 cmH₂O；低值支持容量不足，高值需警惕心功能或肺循环阻力。

考点怎么出：血压升而CVP不明显升支持容量不足；CVP明显升而血压不升警惕心衰。

教材P34

08｜复苏

补液与纠因并行

快速建立静脉通路，晶体液优先，按反应追加并控制出血/感染源。

考点怎么出：“补液”和“纠因”不是二选一，需并行推进。

教材P35—38

09｜体位

中凹卧位

头胸抬高20°—30°，下肢抬高15°—20°，兼顾呼吸和回心血量。

考点怎么出：体位角度和氧疗参数是常见数字考点。

教材P37

10｜感染性

冷暖休克辨析

暖休克可见皮肤较温暖、脉压较大；冷休克表现为外周收缩和低灌注。

考点怎么出：不能因皮肤温暖就排除休克，仍要看灌注与器官功能。

教材P41—42

数值要和意义一起背尿量、休克指数和CVP都在回答同一件事：灌注够不够，心脏能不能承受。

1
原创情境 早期识别

腹腔出血患者烦躁、皮肤苍白湿冷，HR 108次/min，BP 112/86 mmHg。能否排除休克？

  1. A. 能，收缩压正常
  2. B. 不能，脉快和脉压缩小提示代偿期
  3. C. 能，患者清醒
  4. D. 不能，因为一定已到失代偿期

正确答案：B．不能，脉快和脉压缩小提示代偿期

先抓线索：早期识别

判断路径：休克早期血压可维持，脉率增快和脉压缩小可更早提示低灌注。

再想一步：计算脉压26 mmHg，并继续看趋势。

教材依据：教材P33—36

2
原创情境 休克指数

患者HR 120次/min、SBP 80 mmHg，休克指数约为？

  1. A. 0.67
  2. B. 1.0
  3. C. 1.5
  4. D. 2.5

正确答案：C．1.5

先抓线索：休克指数

判断路径：120÷80=1.5，提示存在较明显休克。

再想一步：公式中分母是收缩压，不是舒张压或平均压。

教材依据：教材P36

3
原创情境 尿量

休克患者补液后BP升至105/70 mmHg，但连续2小时尿量仅18 ml/h。对当前组织灌注状态的判断，哪一项最恰当？

  1. A. 灌注已充分
  2. B. 肾灌注仍不足，应继续评估
  3. C. 立即停止监测
  4. D. 仅属正常波动

正确答案：B．肾灌注仍不足，应继续评估

先抓线索：尿量

判断路径：尿量仍低于25 ml/h，提示器官灌注未充分恢复。

再想一步：复苏效果要看器官灌注，不只看血压。

教材依据：教材P36

4
原创情境 CVP组合

一名休克患者BP 78/50 mmHg、CVP 3 cmH₂O，伴脉快、四肢湿冷。这组数据最支持哪一种循环问题？

  1. A. 容量不足
  2. B. 心功能不全
  3. C. 容量过多
  4. D. 无需补液

正确答案：A．容量不足

先抓线索：CVP组合

判断路径：低血压合并低CVP支持回心血量和血容量不足。

再想一步：若CVP高而血压低，思路要转向心泵或阻力问题。

教材依据：教材P34、37

原创情境 补液试验

休克患者快速输入NS 250 ml后，CVP升高4 cmH₂O而血压无改善。护士应如何解读这一补液试验结果？

  1. A. 血容量不足可继续快速补液
  2. B. 心功能不全可能
  3. C. 休克已纠正
  4. D. 测量一定错误

正确答案：B．心功能不全可能

先抓线索：补液试验

判断路径：CVP明显上升而血压不升说明心脏难以把增加的前负荷转为有效输出。

再想一步：此时盲目追加液体可能加重肺水肿。

教材依据：教材P37

原创情境 体位

一名休克患者循环初步稳定，已排除颅脑、脊柱和骨盆损伤等体位禁忌。护士应为其采取什么体位，并说出头胸部和下肢的抬高角度？

先抓线索：体位

判断路径：头胸抬高20°—30°、下肢抬高15°—20°，兼顾呼吸与回流。

原创情境 低血容量休克

一名开放性骨折患者持续出血，已出现脉快、皮肤湿冷和血压下降。当前首要的复苏策略是什么？

  1. A. 只给升压药
  2. B. 快速建立通路补充容量并控制出血
  3. C. 等待血压自行恢复
  4. D. 仅给镇痛

正确答案：B．快速建立通路补充容量并控制出血

原创情境 感染性休克

高热患者皮肤温暖潮红、脉快、血压下降。是否可排除休克？

  1. A. 可排除
  2. B. 不可，可能是暖休克
  3. C. 可，因为没有四肢冷
  4. D. 只有低体温才是休克

正确答案：B．不可，可能是暖休克

先抓线索：感染性休克

判断路径：感染性休克早期可因外周血管扩张呈暖休克表现。

9
原创情境 酸中毒

休克患者呼吸深快、乳酸升高，最可能的代谢改变是？

  1. A. 代谢性酸中毒
  2. B. 代谢性碱中毒
  3. C. 单纯呼吸性酸中毒
  4. D. 无酸碱变化

正确答案：A．代谢性酸中毒

先抓线索：酸中毒

判断路径：组织低灌注导致无氧代谢和乳酸堆积，形成代谢性酸中毒。

再想一步：深快呼吸多为代偿。

疑似休克患者到达病房，护士最先应做？

  2. B. 快速评估ABC、意识与循环并启动急救

  4. D. 先安排饮食

正确答案：B．快速评估ABC、意识与循环并启动急救

先抓线索：优先顺序

判断路径：先识别并处理气道、呼吸和循环威胁，同时呼叫团队。

06｜带背：把答案说出来

从病例起问：先口述20秒骨架，再展开理由，最后合上答案自测。

主动回忆
问题一｜一位“外科休克病人的护理”相关患者初始出现“血压尚正常＋脉快＋脉压缩小”，随病程或治疗进展又出现“HR 120、SBP 80”。新变化出现后，你会怎样重新安排判断与护理优先级？

20秒答题骨架

组织灌注不足 → 按病因识别 → 代偿到失代偿
  • 组织灌注不足：有效循环血量锐减导致微循环障碍、细胞缺氧和代谢紊乱。
  • 按病因识别：低血容量、感染、心源性、神经源性和过敏性休克处理重点不同。
  • 代偿到失代偿：早期脉快、脉压差小、皮肤凉；进展后血压下降、少尿与意识障碍加重。
