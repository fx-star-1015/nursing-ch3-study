02｜等渗

水钠成比例丢失

03｜低渗

失钠多于失水

血钠<135 mmol/L，常无明显口渴；严重时循环和神经症状突出。

教材P10—11
04｜高渗

失水多于失钠

血钠>150 mmol/L，口渴明显；先补水分，分次纠正。

教材P12—13
05｜水中毒

水过多且排出不足

稀释性低钠与脑水肿可使神经精神症状较早出现。

教材P13—14
06｜低钾

兴奋性与动力下降

乏力、腹胀、腱反射减弱和心电图改变；补钾必须遵守安全界限。

教材P14—16
07｜高钾

心脏风险突出

四肢无力、心率慢或心律失常；严重者可心搏骤停。

教材P16—18
08｜代酸

HCO₃⁻原发下降

深大呼吸、灌注不足、酸性产物积聚；纠因和改善循环是根本。

教材P22—24
09｜代碱

失H⁺或HCO₃⁻增多

呕吐、胃肠减压和低钾常见；补液、补氯和补钾需结合病因。

教材P24—25
10｜呼吸性

PaCO₂原发改变

通气不足致呼酸；过度通气致呼碱，处理首先回到通气原因。

03｜核心知识卡

每张卡回答“是什么、为什么、题目怎么用”。

教材印刷页
K1

等渗性缺水

水和钠按比例丢失，细胞外液量下降，血清钠常正常。

题目怎么用：见呕吐、肠瘘等且血钠正常，优先考虑等渗；补液首选平衡盐。

教材P8—10

K2

低渗性缺水

失钠多于失水，血清钠低于135 mmol/L；中度低于130，重度低于120。

题目怎么用：无明显口渴而乏力、直立性低血压、低钠，方向指向低渗。

教材P10—11

K3

高渗性缺水

失水多于失钠，教材以血清钠高于150 mmol/L作为诊断线索。

题目怎么用：明显口渴、高钠和细胞脱水表现相互印证；补水不可过快。

教材P12—13

K4

水中毒

摄水过多或排水障碍导致稀释性低钠与细胞水肿，脑细胞水肿最危险。

题目怎么用：大量低渗液输入后出现头痛、躁动、意识改变，先考虑急性水中毒。

教材P13—14

K5

低钾血症

血钾低于3.5 mmol/L，常见肌无力、腹胀、反射减弱与心电图改变。

题目怎么用：胃肠丢失、长期禁食和排钾利尿后出现乏力，先查钾。

教材P14—16

K6

静脉补钾安全线

见尿补钾；浓度一般不超过0.3%，速度不超过60滴/分，成人每日常补40—80 mmol。

题目怎么用：题目出现无尿、快速静推或高浓度补钾，均为危险信号。

教材P15—16

K7

高钾血症

血钾高于5.5 mmol/L，最危险的是严重心律失常和心搏骤停。

题目怎么用：肾功能不全、挤压伤或酸中毒伴心电异常时优先处理高钾。

教材P16—18

K8

酸碱判断主轴

pH决定酸碱方向；HCO₃⁻代表代谢因素，PaCO₂代表呼吸因素。

题目怎么用：先看pH，再看哪一项变化能解释方向，最后考虑代偿。

教材P21—22

K9

代谢性酸碱失衡

代酸为HCO₃⁻下降；代碱为HCO₃⁻上升，常分别见于休克/腹泻与呕吐/胃肠减压。

题目怎么用：先抓病因，再用呼吸深浅和化验确认。

教材P22—25

K10

呼吸性酸碱失衡

通气不足使CO₂潴留形成呼酸；过度通气使CO₂排出过多形成呼碱。

题目怎么用：呼吸系统问题先解决通气，不能只追着pH补药。

教材P25—28

04｜原创训练 1—10

不背题目，练线索、因果和条件变化。

情境迁移
1
情境训练 等渗性缺水

肠梗阻患者呕吐2天，口干、脉快、血压下降，Na⁺ 140 mmol/L。最可能是？

  1. 等渗性缺水
  2. 低渗性缺水
  3. 高渗性缺水
  4. 水中毒

答案：A

为什么：存在消化液丢失和细胞外液不足，血钠仍在正常范围。

思考提醒：若持续只补水不补钠，状态可能向低渗方向变化。

依据：教材P8—10

2
情境训练 低渗性缺水

术后引流量大，患者乏力、站立头晕但不口渴，Na⁺ 128 mmol/L。判断？

  1. 轻度高渗
  2. 中度低渗
  3. 水中毒
  4. 高钾

答案：B

为什么：低钠、失液病史、循环表现和不明显口渴共同指向中度低渗。

思考提醒：单看低钠不足以定水中毒，还要看丢失与输入史。

依据：教材P10—11

3
情境训练 高渗性缺水

高热患者不能饮水，极度口渴，Na⁺ 154 mmol/L。首要补液方向？

  1. 快速高浓度盐水
  2. 补充水分并分次纠正
  3. 立即补钾
  4. 限制液体

答案：B

为什么：失水多于失钠，应补充水分，避免血钠下降过快。

思考提醒：循环不稳定时仍先保循环，再调整游离水。

依据：教材P12—13

4
情境训练 水中毒

肾功能不全患者短时间输入大量低渗液后头痛、躁动、呕吐。最需警惕？

  1. 急性水中毒
  2. 单纯低钾
  3. 高渗性缺水
  4. 代谢性碱中毒

答案：A

为什么：水排出障碍加大量低渗输入，可致稀释性低钠和脑水肿。

思考提醒：神经精神症状是脑细胞水肿的重要线索。

依据：教材P13—14

5
情境训练 低钾

胃肠减压3天后患者乏力、腹胀、腱反射减弱。最可能异常？

  1. 低钾
  2. 高钾
  3. 高钠
  4. 呼吸性酸中毒

答案：A

为什么：持续胃液丢失和摄入不足易导致低钾，表现为肌肉和胃肠动力下降。

思考提醒：同时评估代谢性碱中毒。

依据：教材P14—16、24—25

6
情境训练 补钾

患者K⁺ 2.9 mmol/L，尿量15 ml/h。此时最不合适的是？

  1. 复查肾功能
  2. 先改善灌注并监测尿量
  3. 立即静脉补钾
  4. 监测心电图

答案：C

为什么：尿量不足时补钾易蓄积，引发致命高钾。

思考提醒：见尿补钾是安全闸门，不只是一句口诀。

依据：教材P15—16

7
情境训练 高钾

挤压伤患者K⁺ 6.4 mmol/L并出现心电异常，护理优先关注？

  1. 皮肤干燥
  2. 心律与循环
  3. 食欲
  4. 睡眠

答案：B

为什么：高钾最紧迫的风险是恶性心律失常和心搏骤停。

思考提醒：优先级由危险决定，不由症状是否舒适决定。

依据：教材P16—18

8
情境训练 代谢性酸中毒

感染性休克患者深大呼吸，pH 7.26、HCO₃⁻下降。判断？

  1. 代谢性酸中毒
  2. 代谢性碱中毒
  3. 呼吸性酸中毒
  4. 呼吸性碱中毒

答案：A

为什么：pH低表示酸血症，HCO₃⁻原发下降并有休克病因。

思考提醒：深快呼吸是代偿表现，不等同呼吸性碱中毒。

依据：教材P22—24

9
情境训练 代谢性碱中毒

幽门梗阻患者频繁呕吐，pH升高、HCO₃⁻升高。判断？

  1. 代谢性酸中毒
  2. 代谢性碱中毒
  3. 呼吸性酸中毒
  4. 高钾血症

答案：B

为什么：胃酸丢失使H⁺减少，HCO₃⁻相对升高。

思考提醒：继续追问常伴低氯、低钾。

依据：教材P24—25

10
情境训练 呼吸性酸中毒

慢阻肺患者嗜睡，PaCO₂升高、pH下降。首要处理方向？

  1. 改善通气
  2. 快速大量补碱
  3. 限制氧合监测
  4. 仅补钾

答案：A

为什么：CO₂潴留的根本问题是通气不足。

思考提醒：抓原发改变：PaCO₂升高解释pH下降。

依据：教材P25—26

先写出因果链再选答案即使暂时选错，只要能找出断掉的一环，下次就会更稳。

11
真题练习 补液选择
完整版山西医科大学2011护理综合，PDF P10

等渗性脱水患者首选的补液是？

  1. 平衡盐溶液
  2. 10%葡萄糖
  3. 纯水
  4. 高渗盐水

答案：A

为什么：平衡盐更接近细胞外液组成，适合恢复容量。

思考提醒：大量单用生理盐水要警惕高氯性酸中毒。

依据：教材P8—10

12
真题练习 输液并发失衡
完整版吉林大学2018护理综合，PDF P7

等渗性缺水患者大量输入生理盐水，可能导致？

  1. 低氯性酸中毒
  2. 高氯性酸中毒
  3. 呼吸性碱中毒
  4. 高钙血症

答案：B

为什么：生理盐水氯含量较高，大量输入可形成高氯性酸中毒。

思考提醒：看清是“生理盐水过量”而非平衡盐。

依据：教材P9—10

13
真题练习 低钠分级
完整版中南大学2018护理综合，PDF P6

K⁺ 3.0 mmol/L、Na⁺ 125 mmol/L，最符合？

  1. 低钾＋中度低渗性缺水
  2. 高钾＋高渗性缺水
  3. 低钾＋高渗性缺水
  4. 单纯水中毒

答案：A

为什么：K低于3.5；Na低于130但不低于120，符合中度低渗。

思考提醒：分别给钾和钠定位，再合并判断。

依据：教材P10—16

14
真题练习 高渗补液
完整版四川大学2012护理综合，PDF P10

高渗性缺水患者补液的早期选择是？

  1. 5%葡萄糖液
  2. 浓盐水
  3. 10%氯化钾
  4. 碳酸氢钠

答案：A

为什么：5%葡萄糖代谢后提供水分，可补充失水。

思考提醒：若循环不稳定，容量复苏优先级仍更高。

依据：教材P12—13

15
真题练习 补钾原则
回忆版考点山西中医药大学2023护理综合，PDF P4

静脉补钾原则中错误的是？

  1. 见尿补钾
  2. 控制浓度
  3. 严禁静脉推注
  4. 尿量少时加快补钾

答案：D

为什么：少尿时排钾受限，快速补钾可造成致命高钾。

思考提醒：把浓度、速度、总量和尿量四条一起检查。

依据：教材P15—16

16
真题练习 代酸纠正
完整版吉林大学2017护理综合，PDF P6

纠正代谢性酸中毒时应特别注意哪种离子变化？

  1. Na⁺
  2. K⁺
  3. Cl⁻
  4. Ca²⁺

答案：B

为什么：酸中毒纠正后钾可重新进入细胞，使血钾下降。

思考提醒：治疗前后动态变化比单次结果更重要。

依据：教材P23—24

17
真题练习 代碱病因
完整版四川大学2010护理综合，PDF P4

幽门梗阻反复呕吐最常见的酸碱与电解质组合是？

  1. 高钾高氯性酸中毒
  2. 低钾低氯性碱中毒
  3. 高钠呼吸性碱中毒
  4. 低钠呼吸性酸中毒

答案：B

为什么：胃酸和氯丢失，加上继发性排钾，形成低钾低氯性代谢性碱中毒。

思考提醒：病因—丢失成分—化验变化逐步推。

依据：教材P24—25

18
真题练习 呼酸机制
完整版四川大学2011护理综合，PDF P6

呼吸性酸中毒的基本机制是？

  1. CO₂排出障碍
  2. HCO₃⁻大量丢失
  3. 过度通气
  4. 胃酸丢失

答案：A

为什么：肺泡通气不足使CO₂潴留，PaCO₂上升。

思考提醒：呼吸性看PaCO₂，代谢性看HCO₃⁻。

依据：教材P25—26

19
真题练习 水中毒
完整版暨南大学2013护理综合，PDF P5

最早出现神经精神症状的水代谢紊乱是？

  1. 急性水中毒
  2. 轻度等渗缺水
  3. 慢性高渗缺水
  4. 轻度低钾

答案：A

为什么：急性低钠使水进入脑细胞，可迅速出现头痛、躁动和意识变化。

思考提醒：看到大量入水、排水障碍和脑症状要联想脑水肿。

依据：教材P13—14

20
真题练习 高钾危险
完整版吉林大学2018护理综合，PDF P8

高钾血症比低钾更紧急的主要原因是？

  1. 一定引起口渴
  2. 可迅速导致心律失常和心搏骤停
  3. 一定导致腹泻
  4. 只影响骨骼肌

答案：B

为什么：心肌电活动受影响可造成致命事件。

思考提醒：严重程度取决于心电和循环风险，而不只看肌无力。
