01｜总序

三步判断

先容量、再电解质、后酸碱；同时守住循环、意识和心律。

考点怎么出：见呕吐、肠瘘等且血钠正常，优先考虑等渗；补液首选平衡盐。

教材P7—28

02｜等渗

水钠成比例丢失

血钠常在正常范围；先用平衡盐溶液，警惕大量生理盐水致高氯性酸中毒。

考点怎么出：无明显口渴而乏力、直立性低血压、低钠，方向指向低渗。

教材P8—10

03｜低渗

失钠多于失水

血钠<135 mmol/L，常无明显口渴；严重时循环和神经症状突出。

考点怎么出：明显口渴、高钠和细胞脱水表现相互印证；补水不可过快。

教材P10—11

04｜高渗

失水多于失钠

血钠>150 mmol/L，口渴明显；先补水分，分次纠正。

考点怎么出：大量低渗液输入后出现头痛、躁动、意识改变，先考虑急性水中毒。

教材P12—13

05｜水中毒

水过多且排出不足

稀释性低钠与脑水肿可使神经精神症状较早出现。

考点怎么出：胃肠丢失、长期禁食和排钾利尿后出现乏力，先查钾。

教材P13—14

06｜低钾

兴奋性与动力下降

乏力、腹胀、腱反射减弱和心电图改变；补钾必须遵守安全界限。

考点怎么出：题目出现无尿、快速静推或高浓度补钾，均为危险信号。

教材P14—16

07｜高钾

心脏风险突出

四肢无力、心率慢或心律失常；严重者可心搏骤停。

考点怎么出：肾功能不全、挤压伤或酸中毒伴心电异常时优先处理高钾。

教材P16—18

08｜代酸

HCO₃⁻原发下降

深大呼吸、灌注不足、酸性产物积聚；纠因和改善循环是根本。

考点怎么出：先看pH，再看哪一项变化能解释方向，最后考虑代偿。

教材P22—24

09｜代碱

失H⁺或HCO₃⁻增多

呕吐、胃肠减压和低钾常见；补液、补氯和补钾需结合病因。

考点怎么出：先抓病因，再用呼吸深浅和化验确认。

教材P24—25

10｜呼吸性

PaCO₂原发改变

通气不足致呼酸；过度通气致呼碱，处理首先回到通气原因。

考点怎么出：呼吸系统问题先解决通气，不能只追着pH补药。

教材P25—28

1
情境训练 等渗性缺水

肠梗阻患者呕吐2天，口干、脉快、血压下降，Na⁺ 140 mmol/L。最可能是？

  1. 等渗性缺水
  2. 低渗性缺水
  3. 高渗性缺水
  4. 水中毒

先抓线索：等渗性缺水

判断路径：存在消化液丢失和细胞外液不足，血钠仍在正常范围。

答案：A

再想一步：若持续只补水不补钠，状态可能向低渗方向变化。

教材依据：教材P8—10

2
情境训练 低渗性缺水

术后引流量大，患者乏力、站立头晕但不口渴，Na⁺ 128 mmol/L。判断？

  1. 轻度高渗
  2. 中度低渗
  3. 水中毒
  4. 高钾

先抓线索：低渗性缺水

判断路径：低钠、失液病史、循环表现和不明显口渴共同指向中度低渗。

答案：B

再想一步：单看低钠不足以定水中毒，还要看丢失与输入史。

教材依据：教材P10—11

3
情境训练 高渗性缺水

  2. 补充水分并分次纠正
  3. 立即补钾
  4. 限制液体

先抓线索：高渗性缺水

判断路径：失水多于失钠，应补充水分，避免血钠下降过快。

答案：B

再想一步：循环不稳定时仍先保循环，再调整游离水。

教材依据：教材P12—13

情境训练 水中毒

  3. 高渗性缺水
  4. 代谢性碱中毒

先抓线索：水中毒

判断路径：水排出障碍加大量低渗输入，可致稀释性低钠和脑水肿。

答案：A

  2. 高钾
  3. 高钠
  4. 呼吸性酸中毒

先抓线索：低钾

判断路径：持续胃液丢失和摄入不足易导致低钾，表现为肌肉和胃肠动力下降。

答案：C

  2. 代谢性碱中毒
  3. 呼吸性酸中毒
  4. 呼吸性碱中毒

先抓线索：代谢性酸中毒

  3. 呼吸性酸中毒
  4. 高钾血症

先抓线索：代谢性碱中毒

  4. 仅补钾

先抓线索：呼吸性酸中毒

答案：A

07｜联动护理学导论

导论概念可以在不同疾病中反复出现；每次都要解释它与本章患者的具体关系。

导论贯穿

一位正在经历“水、电解质代谢紊乱和酸碱平衡失调病人的护理”相关治疗的患者，在完成等渗性缺水评估后问：“你们说的治疗我在配合，可我最担心的是以后还能不能像原来那样生活。”护士先确认安全，再听他讲清最在意的功能、角色与家庭安排。

一般系统理论

人体、家庭和医疗环境都是开放系统；一个环节变化会影响其他环节。

回到故事：一个症状或治疗变化会怎样传导到全身和家庭？

落到本章：画出输入、过程、输出与反馈，并标出护理可干预处。
