03｜核心知识卡

每张卡回答“是什么、为什么、题目怎么用”。

教材印刷页
K1

外科护理学的定义

外科护理学是在现代医学模式指导下，研究外科病人身心整体护理规律的临床护理学科。

题目怎么用：遇到定义题要同时抓住对象、整体性和临床护理学科三个要素。

教材P2

K2

外科疾病六类

损伤、感染、肿瘤、畸形、梗阻和功能障碍构成常见分类。

题目怎么用：题干给病因或病理状态时，先把它归入类别，再调用对应护理逻辑。

教材P2

K3

现代外科学发展的条件

麻醉解决疼痛，无菌与抗菌降低感染，止血和输血改善出血与休克处置。

题目怎么用：不要只背年代，要把突破与它解决的临床障碍配对。

教材P2

K4

南丁格尔与外科护理

改善通风、清洁、饮食和护理组织，使伤员病死率由约42%降至2.2%。

题目怎么用：数字题要连同措施和意义一起记，避免只认人名。

教材P2

K5

连续照护

外科护理范围由住院期扩展到预防、急救、围术期、康复、社区与家庭。

题目怎么用：出现出院随访、康复指导或家庭支持时，判断为连续护理的延伸。

教材P3

K6

以人为中心

同时关注疾病、功能、心理、社会角色和价值选择。

题目怎么用：最佳护理通常不是只处理生理指标，而是兼顾安全、参与和尊严。

教材P3—4

K7

护理程序

评估、护理诊断/问题、计划、实施、评价构成循环。

题目怎么用：方案题先评估再干预；新情况出现后重新评价并调整。

教材P4

K8

个体化整体护理

同一疾病因年龄、基础病、家庭支持和恢复目标不同，护理计划也应不同。

题目怎么用：题干出现个体差异时，不选机械套用常规的选项。

教材P4

K9

外科护士专业素质

包括职业道德、专业知识技能、人文素养、沟通协作和身心素质。

题目怎么用：辨析题注意“专业素质”不是单纯操作熟练。

教材P5—6

K10

临床判断与协作

复杂病情需要持续观察、及时报告、团队沟通和共同决策。

题目怎么用：优先题先处理威胁生命的问题，同时明确护士独立与协作职责。

教材P3—6

情境迁移
1
情境训练 学科定位

患者说“护士不就是执行医嘱吗？”最能体现现代外科护理定位的回答是？

  1. 只完成治疗操作
  2. 围绕患者健康问题实施连续的整体护理
  3. 只负责术后观察
  4. 仅提供生活照顾

答案：B

为什么：现代外科护理以人的健康为中心，护士需要评估、判断、实施并评价护理。

思考提醒：若题干改成“出院后继续随访”，仍属于连续照护。

依据：教材P2—4

2
情境训练 疾病分类

机械性肠梗阻在外科疾病分类中首先属于哪一类？

  1. 感染
  2. 畸形
  3. 梗阻
  4. 损伤

答案：C

为什么：题干已经给出机械性通路受阻，核心病理状态是梗阻。

思考提醒：疾病可能合并感染，但分类先抓主要矛盾。

依据：教材P2

3
情境训练 历史逻辑

  1. 输血
  2. 麻醉
  3. 营养支持
  4. 康复护理

答案：B

为什么：麻醉直接解决手术疼痛与操作耐受问题。

思考提醒：把每项突破和其解决的问题配对。

依据：教材P2

情境训练 历史数据

南丁格尔降低伤员病死率的核心方式是？

  2. 改善环境与系统护理
  3. 扩大药物剂量
  4. 缩短住院时间

答案：B

为什么：她通过清洁、通风、营养和护理组织改善结局。

思考提醒：数字背后考的是护理措施能改变健康结局。

  2. 连续照护
  3. 只重技术
  4. 疾病中心模式

答案：B

为什么：服务从住院期延伸到家庭和社区。

思考提醒：看到出院、家庭、社区、随访就联想到连续性。

依据：教材P3

情境训练 护理程序

护士发现术后患者突发气促，下一步最先做什么？

  2. 立即评估气道呼吸循环并报告
  3. 等待常规查房
  4. 先记录再观察

答案：B

为什么：护理程序从评估开始，且威胁生命时按紧急优先顺序处理。

思考提醒：先处理安全，再补充完整评估与记录。

情境训练 个体化

  3. 结合风险、功能和个人目标调整
  4. 由家属单独决定

答案：C

为什么：整体护理既遵循原则，也回应个体差异。

思考提醒：标准流程提供底线，个体信息决定具体重点。

依据：教材P4

情境训练 专业素质

以下哪项最能体现慎独？

  2. 独立值班时仍严格执行查对

  4. 错误后不记录

答案：B

为什么：慎独强调无外在监督时仍遵守专业与伦理规范。

思考提醒：伦理题先看是否保护安全、诚实和尊严。

情境训练 人文关怀

  2. 承认焦虑并用可理解语言核实其担忧
  3. 只递宣传单
  4. 请家属代答

答案：B

为什么：倾听、共情和清晰沟通能支持患者参与。

思考提醒：先回应情绪，再提供信息并确认理解。

依据：教材P5—6

情境训练 团队协作

患者出现护士权限外的快速恶化征象，正确做法是？

  1. 自行修改全部治疗
  2. 继续观察到交班
  3. 立即采取职责内急救并呼叫团队
  4. 避免记录

答案：C

为什么：护士既要快速行动，也要认识专业边界并有效协作。

思考提醒：协作不是等待，而是同步评估、处置和上报。

依据：教材P3—6
