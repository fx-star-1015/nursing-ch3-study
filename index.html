M1

医院感染：先判边界，再拆感染链

能判断是否属于医院感染，并从感染源、传播途径、易感人群三个环节提出控制思路。

M1-K1

医院感染的判断边界

住院期间获得、可在住院期间或出院后发病；入院前已经存在或处于潜伏期的感染通常不纳入。医务人员在医院内获得的感染也属于医院感染。判断应结合潜伏期、上次住院史、原感染基础上是否出现新的病原体或部位等条件。

教材第25页

M1-K2

感染不等于定植

只有检出微生物、没有临床症状或炎症证据时，不能只凭培养阳性直接判定为感染。

教材第25页

M1-K3

内源性与外源性

分类依据是病原体来源：来自患者自身正常菌群或潜在病灶为内源性；来自其他患者、医务人员、环境或器械等为外源性。不要按发病早晚分类。

教材第25–26页

M1-K4

发生原因

可从宿主因素、诊疗因素、环境与管理因素分析。侵入性操作会突破屏障，基础病、免疫抑制、营养状况等会增加易感性。

教材第26页

M1-K5

感染链

医院感染发生需要感染源、传播途径和易感人群三个基本环节。控制措施应说明切断了哪一环，而不是罗列动作。

教材第27–28页

M1-K6

传播途径与手

接触传播可分直接与间接接触；医务人员的手是重要的间接传播媒介。教材还列出空气、飞沫及其他途径。

教材第27–28页

M1-K7

防控是系统工程

建立责任体系、监测、培训、规范诊疗、改善环境与切断感染链需要协同。单靠一次消毒不能替代持续管理。

教材第28–29页

M2

清洁、消毒与灭菌：对象—风险—方法—监测

能依据目标层级和物品特性选择处理路径，并识别‘参数正确但过程失败’的风险。

M2-K1

三个层级

清洁是去除污染物并降低微生物负荷，通常是后续处理的前提；消毒杀灭或清除传播媒介上的病原微生物，但未必达到杀灭全部微生物；灭菌要求杀灭或清除一切微生物。

教材第30–31页

M2-K2

随时与终末消毒

随时消毒在传染源仍存在期间及时处理污染；终末消毒在传染源离开疫源地后进行彻底处理。二者按时点和目的区分。

教材第31页

M2-K3

干热与湿热

湿热穿透性通常更强，可在较低温度、较短时间完成处理；干热适用于耐高温而不宜湿处理的物品。油脂、粉剂等不适合压力蒸汽灭菌。

教材第31–33页

M2-K4

灭菌效果监测

物理、化学和生物监测各自回答不同问题，不能把化学指示物变色等同于整批物品无菌。预真空压力蒸汽灭菌还涉及B-D试验。

教材第32页

M2-K5

化学消毒的共同逻辑

先按要求清洁、干燥，打开关节或管腔并保证完全接触；效果由浓度、时间、温度、有机物、物品结构和操作共同决定。

教材第35–37页

M2-K6

器械处理按风险分层

进入人体组织、无菌器官或接触破损黏膜的物品，应达到与风险相匹配的消毒或灭菌水平；选择方法还要考虑耐热、耐湿及材质。

教材第43–45页

M2-K7

流程方向

复用器械处理强调污染物品由污到洁的单向流程；消毒供应中心空气流向则强调由洁到污，污染区相对负压、检查包装及灭菌区相对正压。

教材第44页

M2-K8

追溯与发放

包装、标识、灭菌、储存、发放和记录构成追溯链。包装潮湿、破损、指示异常或超过有效期时不能按无菌物品发放。

教材第44–45页

M3

手卫生：时机优先，方法与污染状态匹配

能在临床情境中选择洗手、卫生手消毒或外科手消毒，并解释选择依据。

M3-K1

三种手卫生

手卫生包括洗手、卫生手消毒和外科手消毒。洗手以皂液和流动水去除污垢及部分微生物；卫生手消毒用于减少手部暂居菌；外科手消毒还要求最大限度减少常居菌并抑制再生。

教材第46、49–50页

M3-K2

五个时刻

接触患者前、清洁/无菌操作前、可能接触体液后、接触患者后、接触患者周围环境后。‘戴了手套’不会取消这些时机。

教材第46、49页

M3-K3

暂居菌与常居菌

暂居菌较易通过常规手卫生清除，是交叉传播控制重点；常居菌稳定定植，外科手消毒重点是尽量减少并抑制其快速再生。

教材第47、50页

M3-K4

何时必须洗手

手部有血液、体液等肉眼可见污染，或可能接触艰难梭菌、肠道病毒等对速干手消毒剂不敏感的病原体时，应使用流动水和洗手液洗手。

教材第49页

M3-K5

揉搓要点

揉搓覆盖掌、背、指缝、指背、拇指、指尖等部位，教材要求揉搓至少15秒；冲洗时防止已清洁部位再污染。

教材第48–49页

M3-K6

外科手消毒

核心目标是清除污物和暂居菌，最大限度减少常居菌并抑制再生；不同患者手术之间、手套破损或手被污染时需重新进行。具体产品用量和时间按说明与机构规范执行。

教材第50–51页

M3-K7

依从率

手卫生依从率＝实际执行手卫生的时机数÷应执行手卫生的时机数×100%。既要看是否执行，也要观察方法是否正确。

教材第50页

M4

无菌技术：划清边界，防止跨越与回流

能围绕无菌区、接触面、时间和物品流向判断操作是否污染。

M4-K1

四个概念

无菌区与无菌物品都以‘已灭菌且未被污染’为前提；虽经灭菌但后来被污染，仍属于非无菌区或非无菌物品。

教材第52页

M4-K2

操作原则

环境清洁、人员准备、无菌物品有序管理、面向无菌区、手臂保持在腰部或操作台面以上、避免跨越和谈笑咳嗽；可疑污染即按污染处理，一套物品供一位患者使用。

教材第52页

M4-K3

持物钳

取放时钳端闭合并避免触及容器口；使用时钳端向下、在视线内就地使用。教材的干式保存无菌持物钳开包后4小时更换。

教材第53页

M4-K4

无菌容器与无菌包

容器盖内面向上，手不触及内面和边缘；取出的物品不得放回。教材写明无菌容器初次使用后不超过24小时，部分取用后的无菌包按原折痕包好并标记，限24小时内使用。

教材第54、56页

M4-K5

无菌盘

治疗巾内面构成无菌区，放置物品后覆盖并记录铺盘时间；教材规定铺好的无菌盘尽早使用且不超过4小时。

教材第56–57页

M4-K6

倒取无菌溶液

核对名称、浓度、有效期及容器完整性；倒液时瓶签向掌心、避免瓶口接触容器，已倒出的液体不得倒回。教材对开启后余液的用途有附加限制，不能只背‘24小时’。

教材第58页

M4-K7

无菌手套

未戴手套的手只能接触手套内面，戴好手套的手只能接触手套外面；破损或可疑污染立即更换。脱手套后仍需洗手。

教材第58–60页

M5

隔离技术：标准预防打底，按传播途径加层

能区分三区两通道、三类传播隔离与保护性隔离，并按预期暴露选择防护用品。

M5-K1

三区两通道

清洁区、潜在污染区、污染区按受污染风险划分；医务人员通道与患者通道分设，缓冲间位于区域之间，两侧门不应同时开启。

教材第61–62页

M5-K2

标准预防

把所有患者的血液、体液、分泌物（汗液除外）、非完整皮肤和黏膜视为可能含感染因子；措施包括手卫生、按预期暴露选用个人防护用品、安全注射以及污染物品和器械处理。

教材第63页

M5-K3

传播途径隔离

接触、空气、飞沫等隔离是在标准预防基础上的附加措施；同一疾病存在多种传播途径时，应叠加相应措施。教材隔离标志：接触蓝色、空气黄色、飞沫粉色。

教材第63–65页

M5-K4

空气与飞沫

教材隔离章节把肺结核、水痘列为空气传播隔离；空气传播强调单间或同病原安置、关闭通向走廊门窗、负压病房等。飞沫传播强调距离、通风、患者口罩和近距离防护。

教材第64–65页

M5-K5

保护性隔离

对象是抵抗力低下或极易感染者，目标是保护患者；病室采用正压通风并限制未经处理的物品和有呼吸道症状人员进入。

教材第65–66页

M5-K6

口罩与呼吸防护

一般诊疗、飞沫暴露与空气传播场景使用的口罩类型不同；医用防护口罩佩戴后需做密合性检查，摘除时避免触碰污染面。

教材第66–68页

M5-K7

隔离衣与防护服

是否使用取决于隔离类型与预期暴露。穿脱过程中要识别清洁面与污染面，避免手和工作服接触污染外表；潮湿、破损或污染时及时更换。

03｜理解后再背：5条作答路径

先按因果链想清楚，再用一句骨架把答案提出来。

知其然，也知其所以然
能讲清逻辑，就是在真正掌握。暂时背不顺没有关系，先沿着判断路径说一遍，理解会帮助记忆慢慢变牢。

医院感染

理解链：判边界 → 找病原体来源 → 拆感染链 → 把措施放到对应环节

最小背诵骨架：先判是不是，再看从哪来；抓源、断路、护易感。

真题常见问法：定义辨析、是否属于院感、感染源/途径、病例防控

清洁·消毒·灭菌

理解链：看物品用在哪里 → 定风险等级 → 看材质耐受 → 选方法 → 用监测证明过程

最小背诵骨架：先看用在哪，再定杀到哪；再看耐什么，最后证实到没到。

真题常见问法：概念比较、方法选择、不适用物品、监测意义

手卫生

理解链：先认时机 → 看有无可见污染/特殊病原体 → 选洗手或手消毒 → 覆盖部位与时间 → 判断手套关系

最小背诵骨架：先找时机，再看污染；方法匹配，手套不替。

真题常见问法：五个时刻、洗手指征、外科手消毒、菌落标准

无菌技术

理解链：先划无菌/非无菌 → 查空间 → 查接触面 → 查流向 → 查时效

最小背诵骨架：不跨、不碰、不回流、不过时；可疑即污染。

真题常见问法：原则纠错、持物钳、无菌盘、倒液、戴手套、4h/24h

隔离技术

理解链：所有人先做标准预防 → 明确传播途径 → 追加隔离 → 判断保护方向 → 按预期暴露选PPE

最小背诵骨架：人人标准预防；知道途径再加层；负压护外界，正压护患者。

真题常见问法：三区两通道、三类传播隔离、保护性隔离、PPE选择

05｜第一轮：10道原创“为什么题”

先独立作答，再展开答案。目标是能解释判断依据，而不是只猜选项。

理解检验
做错题不是退步，而是把模糊处照亮。先写出自己的理由，再看“为什么”。你正在练习的，是考场上独立判断的能力。
01原创·单项选择

患者入院时无感染表现，住院期间接受侵入性操作，出院后在合理潜伏期内出现与本次住院相关的新感染。最恰当的判断是：A. 出院后发病一定不是医院感染；B. 可能属于医院感染，应结合潜伏期和诊断标准判断；C. 只要超过48小时就是医院感染；D. 只有医务人员感染才算医院感染。

答案：B

为什么：医院感染可以在出院后发病；‘48小时’只适用于无明确潜伏期时的一个判断条件，不能取代完整诊断。

教材依据：教材第25页

02原创·多项选择

关于医院感染链，下列哪些说法正确？A. 包括感染源、传播途径和易感人群；B. 医务人员的手可成为间接接触传播媒介；C. 只要消灭感染源即可保证不再发生感染；D. 控制措施应说明作用于感染链的哪个环节。

答案：A、B、D

为什么：感染发生是多环节共同作用，单一措施不能保证完全阻断。

教材依据：教材第27–28页

03原创·单项选择

关于清洁、消毒和灭菌，下列正确的是：A. 看不见污渍即可视为灭菌；B. 清洁通常是消毒或灭菌前的重要步骤；C. 化学指示物变色即可证明所有微生物已被杀灭；D. 油脂和粉剂首选压力蒸汽灭菌。

答案：B

为什么：清洁去除有机物并为后续处理创造条件；无菌保证不能只靠外观或单一化学指示。

教材依据：教材第30–32页

04原创·多项选择

下列哪些情况应优先用流动水和洗手液洗手？A. 手部有肉眼可见血液；B. 可能接触艰难梭菌；C. 手部无可见污染，普通接触患者前；D. 可能接触对速干手消毒剂不敏感的肠道病毒。

答案：A、B、D

为什么：可见污染及部分对速干手消毒剂不敏感的病原体，需要机械冲洗与洗手液。

05原创·单项选择

铺好的无菌盘在08:00完成并记录，12:30尚未使用，正确处理是：A. 继续使用；B. 重新铺设；C. 只需在表面喷消毒剂；D. 盖上无菌巾后可延长到24小时。

答案：B

为什么：教材规定无菌盘尽早使用且不超过4小时，08:00至12:30已超时。

教材依据：教材第57页

06原创·病例分析

护士从无菌溶液瓶中倒出过量液体，瓶口触到接收容器边缘，又将剩余液体倒回原瓶。请指出至少3处风险，并给出改法。

答案：风险：瓶口接触容器造成污染；已倒出的液体倒回污染余液；倒液量控制不当。改法：倒液时瓶签向掌心，瓶口与容器保持适当距离；先以少量溶液冲洗瓶口并从原处倒出；倒出的液体不回瓶；开启后的余液按教材规定的对象和用途处理。

为什么：重点考查‘接触面’和‘回流’两条无菌边界。

教材依据：教材第58页

07原创·病例分析

一名护士戴手套完成吸痰后，未摘手套直接调节另一位患者的输液泵，随后摘手套但未洗手。请按感染链指出问题和纠正措施。

答案：问题：污染手套把第一位患者/环境的病原体带到另一位患者及设备，形成间接接触传播；摘手套后未手卫生。纠正：不同患者之间更换手套；完成污染操作后摘手套并立即手卫生；按接触患者、体液暴露和患者周围环境后的时机执行。

为什么：手套是屏障，不会自动切断传播；不当使用反而成为传播媒介。

教材依据：教材第27、46、49、60页

08原创·比较简答

比较标准预防、基于传播途径的隔离和保护性隔离：适用对象、核心目标和措施逻辑分别是什么？

答案：标准预防用于所有患者和医务人员，按预期暴露采取手卫生、PPE、安全注射及污染物处理；传播途径隔离用于已知或疑似经接触/空气/飞沫等传播的感染，在标准预防上追加相应措施；保护性隔离用于免疫低下等易感患者，重点阻止外界病原体进入，常涉及正压、限制人员和物品。

为什么：三者不是互相替代，而是对象与保护方向不同。

教材依据：教材第63–66页

09原创·情境决策

病区收治疑似肺结核患者。请用‘患者安置—患者转运—医务人员防护—环境管理’四栏给出隔离要点。

答案：患者安置：优先单间、关闭通向走廊的门窗，有条件使用负压病室；转运：限制不必要转运，病情允许时患者戴外科口罩；医务人员防护：进入时戴医用防护口罩，可能喷溅时加护目镜/面罩和防护服，接触体液时戴手套并手卫生；环境管理：加强通风和空气消毒，规范处理口鼻分泌物及污染物。

为什么：教材隔离章节将肺结核列入空气传播隔离，本题据此完成判断。

教材依据：教材第64–65页

10原创·综合纠错

学生把‘无菌容器、部分取用后的无菌包、无菌盘、干式无菌持物钳、开启的无菌溶液’全部背成24小时。请逐项纠正，并指出最容易被过度简化的一项。

答案：无菌容器初次使用后不超过24小时；部分取用后的无菌包按原折痕包好并标记，限24小时；铺好的无菌盘和干式无菌持物钳均为4小时；开启无菌溶液教材写有24小时信息，但同时限定余液用途，一次性溶液未用完不宜保留，最不能简单归入‘24小时无菌有效期’。

为什么：时间必须与具体对象、开启方式和用途绑定记忆。

教材依据：教材第53–58页

06｜第二轮：10道真题＋解析

每道题都给出判断逻辑，并回扣第7版教材页码。

真题迁移
真题不是用来评价你聪不聪明。它只负责告诉你：哪些已经掌握，哪些值得再看一遍。每一次订正都在缩小未知范围。
走到真题这一步，你已经完成了最难的知识整理。把真题当作一次定位：答对时确认方法，答错时找到下一次进步的具体位置。先说出判断依据，再查看解析。
11复旦大学 2015

油剂、粉剂的消毒宜选择：A. 干烤法；B. 压力蒸汽灭菌法；C. 低温蒸汽消毒法；D. 流通蒸汽消毒法；E. 电离辐射灭菌法。

20暨南大学 2018

答案：适用于抵抗力低下或极易感染者。作答可分：单间或同类患者安置；病室保持正压并加强环境管理；严格手卫生；按风险使用口罩、帽子、隔离衣等；限制探视及有感染症状人员进入；进入物品先清洁/消毒；患者合理饮食、口腔和皮肤护理并监测感染征象。作答时按“人—环境—物品—操作—监测”展开。
